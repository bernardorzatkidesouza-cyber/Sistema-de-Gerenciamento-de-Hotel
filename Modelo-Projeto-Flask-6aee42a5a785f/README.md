# Sistema-de-Gerenciamento-de-Hotel

O projeto consiste no desenvolvimento de um sistema back-end para gerenciamento de um hotel, utilizando a arquitetura de microsserviços. A aplicação terá como finalidade organizar o cadastro de hóspedes, o gerenciamento de quartos, o controle de reservas e o registro de pagamentos.

O sistema permitirá que funcionários realizem cadastros, consultem informações e efetuem reservas, verificando a disponibilidade dos quartos. Também permitirá registrar pagamentos vinculados às reservas, garantindo a comunicação entre os diferentes microsserviços.
