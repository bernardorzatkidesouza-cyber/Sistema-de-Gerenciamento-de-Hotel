SISTEMA DE GERENCIAMENTO DE HOTEL - MICROSSERVICOS COM FLASK
============================================================

O QUE TEM NO PROJETO
- 4 servicos, cada um com sua pasta, porta e banco SQLite proprio:
    servico_hospedes   (porta 5001, hospedes.db)
    servico_quartos    (porta 5002, quartos.db)
    servico_reservas   (porta 5003, reservas.db)
    servico_pagamento  (porta 5004, pagamentos.db)
- Cada servico tem: app.py, models.py, regras.py, rotas.py, integracao.py,
  erros.py e o seu proprio requirements.txt (o Render so enxerga a pasta do servico).
- Os bancos .db sao criados sozinhos quando cada servico e iniciado.
- Hospedes e quartos criam dados de exemplo se o banco estiver vazio.
- Testes da extensao REST Client do VS Code na pasta ../rest-client.
- README.md: documento de requisitos, integracoes e passo a passo do Render.
- DOCUMENTO-TECNICO.md: documento tecnico completo (rotas, modelos, regras, erros).

INTEGRACOES (3)
1. Reservas  -> GET Hospedes   (confere se o hospede existe)
2. Reservas  -> GET Quartos    (confere se o quarto existe e esta disponivel)
3. Pagamento -> PUT Reservas   (confirma a reserva; se falhar, o pagamento e desfeito)

COMO RODAR NO WINDOWS (POWERSHELL)
  cd modelo-projeto-flask
  py -m venv .venv
  .venv\Scripts\Activate.ps1      (se der erro de politica de execucao, rode:
                                    Set-ExecutionPolicy -Scope Process Bypass)
  pip install -r requirements.txt
  .\iniciar_servicos.bat          (abre os 4 servicos, um em cada janela)
Se o Windows perguntar sobre o Firewall, clique em Permitir.

TESTAR
- Instale a extensao "REST Client" no VS Code.
- Abra os arquivos .http da pasta rest-client e clique em "Send Request".
- Ordem: hospedes.http -> quartos.http -> reservas.http -> pagamento.http.

PUBLICAR NO RENDER
- Veja a secao "Publicacao no Render" do README.md.

DICAS
- Use 127.0.0.1 e nao localhost.
- Um servico nunca abre o banco do outro: so pergunta por HTTP.
- Se mudar nomes de campos e o banco antigo der erro, apague o arquivo .db
  da pasta do servico e inicie de novo.
